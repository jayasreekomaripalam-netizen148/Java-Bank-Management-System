# Java Bank Management System

## Project Title
**Java Bank Management System**

A console-based banking application developed using Java that simulates real-world banking operations like customer management, ATM services, UPI transactions, loans, fixed deposits, and admin controls.

---

## Features

### Customer Features
- Customer registration
- Account creation (Savings / Current)
- Secure PIN-based login
- Deposit money
- Withdraw money
- Money transfer
- UPI transfer
- Change PIN
- Update profile details
- View account balance
- View transaction history
- Generate transaction receipts

### ATM Features
- ATM cash withdrawal
- Fast cash option
- Cash deposit
- Balance enquiry
- Mini statement
- PIN change
- ATM card security
- Failed login attempt tracking
- Account freeze/unfreeze system

### Banking Features
- Fixed Deposit creation and management
- Loan application
- Loan EMI payment
- Compound interest calculator
- Transaction tracking
- Customer search
- Customer deletion

### Admin Features
- Admin login
- View all customers
- Admin dashboard
- Total bank balance calculation
- Block/unblock customer accounts
- View all transactions
- Change admin password
- Customer security monitoring
