# 🏦 Java Bank Management System

A complete banking application developed using **Java, Object-Oriented Programming, File Handling, HTML and CSS**.

https://jayasreekomaripalam-netizen148.github.io/Java-Bank-Management-System/


## 📌 Project Overview

Java Bank Management System is a console-based banking application with a modern web interface.

It provides banking operations like:

- Account Management
- ATM Operations
- UPI Payments
- Loan Management
- Fixed Deposits
- Transaction Handling
- Bank Statements
